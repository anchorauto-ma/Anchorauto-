# Anchor Auto Repair Website

Simple static website for Anchor Auto Repair in Clinton, MA.

## Pages/sections

- Home
- About Us
- Contact

## Publish with GitHub Pages

In this repository, go to:

Settings -> Pages -> Build and deployment

Then choose:

- Source: Deploy from a branch
- Branch: main
- Folder: /root

Save the settings. GitHub will create a public Pages URL after the first deployment.
